# ym-sync 0.4.0

- В очереди видно, кто поставил трек
- Порядок очереди меняется перетаскиванием, лишнее можно убрать
- История прослушанного
- Похожие треки и радио по треку
- Альбомы на странице исполнителя
- Пятиполосный эквалайзер
- Медиаклавиши клавиатуры на ПК, громкость стрелками в окне
- Громкость меняется равномерно на слух — тихо теперь действительно тихо

**Важно:** перемещение и удаление треков в очереди работают, когда все устройства комнаты на 0.4.0

**Установка:** Windows — `ym-sync_0.4.0_x64-setup.exe` (или автообновление), Android — `ymsync-0.4.0-android.apk` (ставится поверх прежней версии)
