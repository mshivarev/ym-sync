# ym-sync 0.4.2

- Треки в очереди на ПК теперь перетаскиваются мышью: строка едет за курсором, у краёв список прокручивается, Esc отменяет
- Если окно на ПК выше, чем шире, ползунок громкости встаёт вертикально
- Рассинхрон с комнатой по умолчанию скрыт — включается в настройках, в разделе «Звук»

**Установка:** Windows — `ym-sync_0.4.2_x64-setup.exe` (или автообновление), Android — `ymsync-0.4.2-android.apk` (ставится поверх прежней версии)
